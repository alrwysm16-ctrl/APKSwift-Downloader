# دليل تحديث ونشر الموقع على Netlify (حل مشكلة ظهور الهاتف)

## سبب المشكلة التي ظهرت في لقطة شاشتك على `loader.netlify.app`:
النسخة المرفوعة سابقاً على GitHub كانت تحتوي على:
1. شريط علوي (Header) يضم 7 أزرار أفقية لا تتسع لشاشة الجوال (360px) مما سبب تمدد العرض أفقياً.
2. عناصر خلفية تقنية بمسافات سالبة (`-left-32` و خطوط دوائر بعرض `w-80`) تسببت في دفع الصفحة نحو اليمين وظهور الفراغ الأسود على اليسار في المتصفحات التي تعمل باللغة العربية (RTL).
3. غياب ملف إعدادات `netlify.toml` الخاص بـ Next.js.

---

## ما تم تجهيزه لك في المشروع الآن:
1. **`netlify.toml`**: تم إنشاؤه مسبقاً ومُعد تلقائياً لدعم Next.js 15 مع `@netlify/plugin-nextjs` و Node 20.
2. **`layout.tsx`**: تم ضبط وسوم `Viewport` الرسمية لمنع الشاشة من الانكماش أو الانزياح.
3. **`Header.tsx`**: أصبح متجاوباً بالكامل ومريحاً على شاشة أي هاتف أندرويد.
4. **`globals.css`**: قفل أي تسريب أفقي نهائياً عبر `overflow-x: hidden !important; max-width: 100vw !important;`.

---

## خطوات التحديث على GitHub و Netlify (خلال دقيقة واحدة):

إذا كنت تستخدم Git من جهازك، نفذ الأوامر التالية في مجلد المشروع لرفع التحديثات إلى GitHub:

```bash
git add .
git commit -m "Fix mobile responsive layout and add Netlify configuration"
git push origin main
```

بمجرد عمل `git push`، سيقوم **Netlify** تلقائياً باكتشاف التحديث الجديد وإعادة بناء الموقع (`Building & Deploying`)، وستظهر شاشة هاتفك مضبوطة 100% بدون أي فراغ جانبي وبدون انزياح.

---

## إعدادات Netlify الموصى بها (في حال قمت بضبطها يدوياً):
- **Build command:** `npm run build`
- **Publish directory:** `.next`
- **Node Version:** `20`
